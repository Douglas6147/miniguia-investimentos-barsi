Princípios de Luiz Barsi
 Objetivo

Este projeto tem como objetivo construir um caderno temático sobre investimentos, com base nos princípios de Luiz Barsi, utilizando Inteligência Artificial como ferramenta de aprendizado e organização do conhecimento.

 Curadoria de Fontes

Foram utilizadas diversas fontes como vídeos, artigos e materiais em PDF, selecionados com base em critérios de clareza, confiabilidade e relevância.

 Principais Aprendizados
A disciplina é essencial para a construção de riqueza
Investir em ativos que geram renda passiva
Pensar no longo prazo
Evitar decisões emocionais
Reinvestir os ganhos

 Engenharia de Prompts

A construção de riqueza é um processo de longo prazo que depende de disciplina, consistência e boas decisões financeiras.
